# Third-Party Notices

CINDER is developed with a strict zero external runtime dependency policy.
All core domain logic, algorithms, servers, and controllers run on native Node.js APIs (`node:http`, `node:fs`, `node:path`, `node:test`, `node:crypto`).

---

## Runtime Dependencies

- **External npm runtime packages:** 0
- **External binary dependencies:** None required. Live Elasticsearch cluster connection is completely optional; native embedded engine executes in-process.
