# Getting Support for CINDER

We want your experience building and running CINDER to be productive and reliable. This guide details how to get assistance, report issues, and find answers.

---

- **Frequently Asked Questions:** [docs/kb/faq-and-edge-cases.md](docs/kb/faq-and-edge-cases.md)

- **Operations & Troubleshooting:** [docs/OPERATIONS.md](docs/OPERATIONS.md)

---

## 2. Issue Tracker

If you find a bug or have a feature proposal:

1. **Search Existing Issues:** Check if someone has already reported the issue.
2. **Submit a Bug Report:** Include:
   - Node.js version (`node -v`).
   - Elasticsearch mode (live cluster or embedded engine).
   - Minimal reproduction command or script.
   - Expected vs actual behavior.
3. **Architecture Questions:** Open a discussion on our community forum or GitHub Discussions.
